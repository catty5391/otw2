# 执行计划与任务卡

本文中的 N00～N23 是**待执行任务**。先完成一个有界批次并交付步骤和结果，再按证据选择后续分支；不得把整个路线自动解释为本轮已授权大规模计算。
项目根目录为 `/home/panqiheng/otw2`，Python 为 `.venv/bin/python`。所有相对源码路径以项目根目录为基准。

## 1. 研究问题和交付边界

主线：在当前 Z30103A6 单塔及单塔四跨导线体系下，解释导线对动力特性、风向响应与薄弱部位的影响；明确 TMQ 等效材料在这些结论中的作用与限制。

分开回答四个问题：

1. **模型身份**：质量、预张力、几何、约束、气动力与材料究竟是什么，静力/模态/动力是否一致？
2. **数值可靠性**：重力平衡、振型、加载、阻尼、时间步和非线性路径是否经过独立检查？
3. **物理可靠性**：角钢杆件、线系统和气动力的输入能否由资料或独立参考支撑？
4. **课题结论**：在已经验证的范围内，能否给出单塔/塔线、不同风向的对比及薄弱位置解释？

当前新材料是轴向 TMQ + 弹性弯曲/扭转的 Aggregator，经直杆 Corotational dispBeamColumn 接入。它不是已有缺陷空间纤维梁的自动等价替代。其系数来自管件资料，尚未完成角钢独立验证。
当前没有材料断裂/删除、完整相线/地线/分裂导线体系、相邻塔柔度、气动阻尼或随变形更新的风荷载；需要逐项选择研究范围，不默认全部实现。

### N03 — 将实际风荷载投影到模态并评估截断

- **前置**：N01、N02。
- **步骤**：从现有风计划抽取 0°/45°/90°下塔身、导线、组合荷载。为各网格重新组装相同物理定义的节点向量，不能把 20 段标签套到 80 段。核对六分量、受约束 DOF、总力/总力矩，保留固定端荷载账本。
- 计算 `Q=ΦᵀF`、单荷载静柔度与模态截断贡献；直接解当前重力态 K 的线性扰动作为独立数值参照，报告 40/80/120/160 阶及相同截止频率下的差别。线性扰动不是新的非线性 FE 路径。
- 控制输出至少包括：350 节点 X/Y、沿风/横风、两处悬挂点、各跨中、塔基与远端反力分量；反力/内力要有独立恢复算子或标明尚不可计算，不能由一个位移指标代替。
- **输出**：每阶和成组广义力、截断误差、候选频带、需要扩展的具体模型/频带/输出列表。
- **测试/验收**：力与矩守恒，约束映射一致；不得将 X/Y 质量比强行补至 90% 作为唯一标准。静态通过仅解锁相应静响应，动态频响在 N06/N08 检验。
- **失败出口**：缺荷载来源或不支持内力恢复则该输出受限；投影不充分时给 N06 一个有预算的扩展请求。预算：0 个 FE。

### N07 — 实现独立塔线瞬态适配与解析小试验

- 新域 → 建塔/线 → 一次完整重力 → `loadConst` → 定义阻尼 → 平均风平衡（若该算例需要）→ 重置时程基点且不移除恒载 → 时变风。不得重复重力或把平均风施加两次。
- 节点风向量支持 XYZ+力矩和不同空间分组的时间序列；每组有限单元荷载因子按物理时间插值。角度变化时重建气动力方向，不能用负标量系数假冒 180°风。
- 输出所有 accepted 子步真实时间、u/v/a、载荷账本、惯性/阻尼与约束反力、1528 塔杆端力及线/绝缘子轴力；失败试步不写为已提交记录。未知材料能量写 null+原因。
- **输出**：拟建 `transient.py` 或适配模块、输入 schema、最小示例、测试。设置两次独立运行可重复，异常退出关闭记录器。

### N08 — 全塔/塔线的小扰动、自由衰减和谐波验收
