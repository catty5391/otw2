# 方法、输入协议与验收口径

本文件为后续实现的规格；下面的方法、指标和拟建模块并不表示已经开发或跑通。门槛集中在 [ACCEPTANCE.json](ACCEPTANCE.json)，执行前版本化冻结。改变门槛必须说明原因并重评旧结果，不能针对某次失败临时放宽。

## A. 原始数据与模型身份

每个工况至少记录：`case_id/model_id/state_id`、S2K和源码SHA256、Python/OpenSees/native库版本、材料系数、初缺陷/有效长度、线段数/档距/质量/张力/初始形状、约束、重力状态、风向定义/风速语义/气动力系数/空间荷载、阻尼、积分/求解器、终止条件、实际耗时。

推荐结果目录（**拟建约定**）：

```text
initial_imperfection_material/tian_ma_qu/followup_results/<batch_id>/
  manifest.json                 # 状态/参数/源数据指纹/调用命令
  configs/                      # 运行前冻结，含随机种子与依据
  logs/                         # stdout/stderr/returncode/timeout
  runs/<case_id>/                # 各工况独立，不覆盖历史目录
  diagnostics/                  # 成组模态/投影/误差/质量判定
  figures/                      # SVG + PNG + PDF，保留数值CSV
  REPORT.md
  verification.json
```

现有模态每个 checked 目录中的文件：

- `eigenvectors.npz`：完整六自由度节点振型、节点号、质量、固定标记、初始/重力坐标及重力位移。数值分析用 float64。
- `equation_modes.npz`：自由方程振型、`node_dofs`映射、特征值；不要假设自由方程顺序等于节点排序。
- `stiffness.npz`、`mass.npz`：稀疏 K/M；含无质量自由转动 DOF，M可奇异。
- `viewer_data.json`：压缩精度、显示归一化的展示数据，**不可**作为高精度验收源。
- `modes.csv`、`summary.json`、`opensees_modal_properties.json`：摘要与独立参与量核对。

模态来自无风重力态；若加平均风后提取模态，需另建 `state_id`。不得比较不同状态后只归因于“导线影响”。按受约束/自由DOF分别记质量和载荷；XYZ各向质量相同不等于总物理质量要乘3。

## B. 特征解与质量加权子空间

### B1. 特征解质量

对自由方程满足 `Kφ = λMφ`，`f=sqrt(λ)/(2π)`。逐阶检查有限值、λ>0、`φᵀMφ>0`，质量归一化后 `ΦᵀMΦ≈I`。
统一相对残差：`||Kφ−λMφ||₂ / max(||Kφ||₂+|λ|·||Mφ||₂, tiny)`；tiny只作防零，不掩盖零振型。
在当前正定重力态才使用既有对称稀疏解法；非线性软化后若切线不对称或非正定，先识别性质，不能默认沿用同一假设。
新建议门槛为相对残差和质量正交最大误差均≤1e−6；这比现有程序中某些拒收阈值更严格，是后续验收建议，不能追写成历史测试标准。

### B2. 单模态MAC与成组比较

在共同塔节点平动DOF上取原塔质量矩阵 `W`，剔除零质量方向。对单振型 `a,b`：

`MAC_W(a,b)=|aᵀWb|²/[(aᵀWa)(bᵀWb)]`。

对组矩阵 `A,B`：用 `W^(1/2)A`、`W^(1/2)B` 的SVD构造正交基 `Q_A,Q_B`；奇异值小于相对阈值1e−10的方向标秩亏。`svd(Q_AᵀQ_B)` 是主夹角余弦，报告最小值、平方值及双向投影误差。
组维数不同要报告秩与未覆盖维数，不能只取较小维数的所有高奇异值就称完全相同。对裸塔三个参考形状单独给投影覆盖：`||Q Qᵀ W^(1/2)r||² / ||W^(1/2)r||²`。

候选初筛窗口先固定1.8～2.7Hz；近重根组边缘以相邻频率相对差≤0.1%为初始归组建议，若边界截断整组则扩到完整组并记录，规则先冻结。此数值是识别算法参数，不是物理简并判据。
保留全部候选及低塔体份额者，避免其归一化后形成虚假高MAC；同时显示原始塔体动能份额并使用绝对量保护。公共塔子空间稳定仅证明塔体形状保持，不能替代导线空间响应收敛。

组内各项：频率范围、选模规则、秩、塔/线/绝缘子质量归一化动能分量之和、有效质量组和、对参考形状覆盖。各阶动能份额求和属于子空间的分量迹量，**不是总在0～100%的单模态份额**，不要把它直接标百分比。若比较份额，应预先定义按组总维数或按给定响应谱加权的归一化方式。
由一阶移动到另一阶的份额差不直接等于物理能量转移；需用固定输入响应检验。

导线空间比较：按每条物理跨的归一化材料坐标/弧长重采样，用同一线密度和积分权重；考虑端点与悬挂点边界，保留原网格坐标。不得仅排序节点tag后相减。

## C. 风荷载投影、静柔度与频响

### C1. 方向与载荷台账

现有约定是风力指向角：0°为+X、90°为+Y。沿风单位向量 `e=(cosα,sinα,0)`，横风 `n=(-sinα,cosα,0)`；位移与反力分别投影，转角RZ另报。
六分量载荷为 `[Fx,Fy,Fz,Mx,My,Mz]`，单位为 N/N·m。全局总力矩需要 `r×F+M`，共同固定参考点。杆件分布风与节点荷载同时核对总力、总矩。
显示“控制X位移/H”和“沿风位移/H”两个字段，45°下不可混用。塔基反力与远端锚点反力分别报告，系统平衡使用二者之和以及所有外载。

原20段节点荷载只能用于相同节点拓扑。跨网格保持物理速度/压力场、气动与重力几何定义一致，再在该网格组装；不能为匹配频率而同时调整张力或质量。

### C2. 广义力与静力残余

自由方程模态质量归一化后 `q_force=ΦᵀF_free`。固定DOF上的外载只进反力账本，不进入自由模态投影。转动自由度的力矩照样进入，不因其无转动质量而直接丢弃。
对给定定常荷载 `F`，先解 `K u_static=F_free`，再求 `u_modal=Σ φ_r(φ_rᵀF)/λ_r`；报告每个观察输出以及加权向量范数误差。
M奇异或有限模态遗漏高频弹性变形时，保留 `u_residual=u_static−u_modal`，查明是截断还是无质量自由度的静柔度。需要凝聚时仅在已验证可逆的质量为零子块上做约束一致的静凝聚，保留荷载等效项和输出恢复；不能调用 `inv(M)` 或默默增加转动质量。
残余静力修正只保证零频柔度，不等于任意频率响应精确；同时提供未修正和修正结果。

不定义 `ΣQ_r²/||F||²` 为统一“风参与率”。不同频率、阻尼、观察点及空间互谱都影响响应。

### C3. 频响与空间相关

给定明确的线性阻尼矩阵C：`(K−ω²M+iωC)u(ω)=F(ω)`；观察量 `y=L u`，若有直接载荷项需同时保留。N06先以N04候选C作离线参照，G1为`candidate_linear_C`，记录构造、覆盖、方案ID/指纹、频带和输出。N08实测核对并回检离线频响/截断后，更新为`implemented_C_confirmed`，才允许G2/G3通过；回检不自动增加FE配额。若实际设置不一致，不能把候选C的结论转贴给实际模型。
只在C与M/K共享模态且实测验证时使用逐模态标量分母；否则投影 `C_r=ΦᵀCΦ` 保留模态耦合，或用全矩阵频响作数值参照。分区域阻尼通常不能无条件当成单一比例阻尼。
独立空间风列构成 `B`，模态荷载为 `ΦᵀB`；相关随机输入需 `S_Q=ΦᵀB S_w BᵀΦ` 或直接时域映射。单公共系数的 Path 只代表全相干同形输入。

截断验收：指定输出的静响应相对误差≤2%，带阻尼频响加权L2误差≤5%、共振峰幅误差≤5%；对参考接近0的输出使用预先固定的绝对尺度，另报相位。近共振加密频率到曲线稳定，不能在离散点之间漏掉峰值。
所有频带采用相同单位Hz，`ω=2πf`；同样160阶在20/40/80段覆盖不同频带，不可当成同等截断。
塔杆内力和导线张力需经可信线性恢复算子或实际FE记录核对；没有恢复算子时只承认位移截断结论。

## D. 阻尼与独立数值验证

OpenSees的Rayleigh形式是

`C = αM M + βK K_current + βKi K_initial + βKc K_last_commit`。

若确实是同一K的比例阻尼，`ζ(ω)=0.5(αM/ω+βKω)`；两锚点等阻尼时 `αM=2ζω1ω2/(ω1+ω2)`、`βK=2ζ/(ω1+ω2)`。先核对各单元参与和实际C，不能仅由公式宣称全体系阻尼已正确。
当前0.195Hz导线与2～2.5Hz塔身存在不同时间尺度；只取前两个几乎相同的导线频率拟合会对其他频带造成不合意的阻尼谱。报告整个研究频带和相邻高频谱。

文档说明Rayleigh赋值作用于当时已经定义的节点/单元，且会覆盖已有系数；初始、当前、已提交刚度的含义不同。非线性用途需要额外检查。[OpenSees Rayleigh 官方说明](https://opensees.github.io/OpenSeesDocumentation/user/manual/model/damping/rayleigh.html)

`corotTruss/corotTrussSection`提供`-doRayleigh`且默认0；必须核对节点质量阻尼与元素刚度阻尼分别是否存在。当前代码未显式设置旗标，这是待测的适配事项，不能推断“导线完全无任何阻尼”。[OpenSeesPy Corotational Truss 文档](https://openseespydoc.readthedocs.io/en/latest/src/corotTruss.html)

目标阻尼必须附来源；缺资料时为假设敏感性参数。N04最多3个候选，先选一个主方案用于数值验证，材料物理验证以后也不自动把假设阻尼转为实测。
测量实际自由衰减频率与阻尼；若为近重根混合模态，使用模态投影/频域拟合而不是把拍振包络当耗散。建议频率误差≤1%，阻尼绝对差≤max(0.1个百分点,目标阻尼的10%)。
软化后留意当前K阻尼的性质、初始K阻尼的过量作用；没有核验时不沿用弹性结论。材料滞回参数中名为zeta的系数与结构黏性阻尼比不是同一个物理量。

## E. 瞬态加载、时间和力学验收

### E1. 分析过程

1. 从独立域建模，冻结质量、约束和材料；施加一次完整重力，检查平衡、张力和状态。
2. 把恒载冻结；按选定场景先施加平均风达到平衡，或以明确光滑包络引入总风。两个场景分开命名。
3. 设置阻尼并核查加载标签；记录`domain_time_origin`，所有外部时程使用真实秒数和明确的起终点。
4. 自适应子步只能在同一连续输入上插值；每个接受点保存实际时间，不能按循环索引假设每步等长。
5. 失败尝试不成为已提交状态，不外推缺失尾部；退出时关闭记录器但保留失败证据与已存在恒载的所属关系。

Newmark参数和稳定性不能代替精度检验。初始建议`gamma=.5,beta=.25`，dt由目标频带、输入采样共同决定，再dt/2对照。旧入口的0.001位移范数容差不能未经量纲和响应幅值评估直接作为微幅验收标准。
漂移采用两层代表截面平动与转角的明确定义，沿风/横风分开；直接改`control_dof`不会自动改变旧漂移器的方向。

### E2. 平衡

自由方程残差：`r=F_ext−F_int−M a−C v`（按具体实现的阻尼/非线性内力定义防重复计数）。分别核对平动N和转动N·m，不混为一个带量纲范数。
约束通过变换矩阵消元时，用真实约束映射恢复；全部反力含塔脚与远端固定点。全局平衡另外记录，不用“基底剪力=风总力”处理动态瞬间。
对实现的初始建议容差：自由平动力最大值≤`max(0.1 N,1e−5·force_scale)`；自由转动≤`max(0.1 N m,1e−5·moment_scale)`；scale取完整外/内/惯性/阻尼各项的最大绝对量并记录，不随失败人为扩大。
所有已接受点都需可核查；若资源限制检查采样点，应标明覆盖率，不能声称全时段全部通过。零扰动的漂移≤1e−6m为建议绝对量门槛，检查其对静态重力收敛误差的敏感性。

### E3. 能量

线性小模型与固定重力切线扰动可计算：`T=.5vᵀMv`、`V=.5δuᵀKδu`、`D=∫vᵀCv dt`、`W=∫F_dynamicᵀdδu`，保持基点、恒载和约束功的一致定义。只有这类已知储能模型可用≤1%相对能量闭合误差作验证，归一化尺度采用输入功/峰值储能的最大值并加防零绝对阈值。
全塔大变形TMQ中，`util/postprocess/energy.py`只提供外功；原生材料没有完整可信储能/耗散输出时，缺项必须为`null`及原因，不能计算一个假“总能量守恒通过”。单调曲线面积不是滞回耗能；局部回线积分也须说明所积分的物理共轭量及闭合状态。

### E4. 关键输出

全局：控制节点XYZ、沿/横风与RZ，两个挂点，塔基/远端反力，所有杆件事件及首次位置。
导线：每跨跨中位移、最小/最大张力、各端轴力及实际方向、松弛/压缩标志；绝缘子轴力和方向。
塔杆：原始tag映射、两端六分量内力、TMQ轴向应力/等效应变/分支和历史事件，明确弯矩来自弹性支路。
保存原始轨迹足以支持任意**已记录时间区间**查询；若抽稀则不能承诺子步级重构。

## F. 材料、峰值和误差定义

### F1. 误差

- 频率相对差以较细网格/独立参考为分母；标明比较方向。
- 峰值荷载/位移分别比较，若平顶则输出平台区间，不强求唯一峰值点。
- 曲线只在共同已完成物理区间比较，保留加载次序；单调曲线可按单调位移插值，循环应按协议分支/真实时间配准，不把循环排序成单调曲线。
- NRMSE以参考峰值绝对力归一化；近零参考另用冻结量纲尺度。曲线面积为有符号外功或指定绝对面积，必须声明，不能混用。
- RMS时间步误差≤2%；峰值/关键内力/张力误差≤5%。事件对称组允许并列，报告分辨率与首次发生区间。

### F2. 实际杆件验收建议

参考网格最后两级峰值差≤2%、初始/卸载刚度差≤5%，再考虑标定。未屈服小循环卸载到初始端距时，残余轴力幅≤参考峰值的1%，恢复状态残余端缩≤最大输入端缩的1%（按对应力控/位移控协议分别评价）；同时报告绝对N/mm和参考本身误差。
留出协议的峰值承载差≤5%、初始/卸载刚度差≤10%、共同协议的循环面积差≤15%；残余变形差≤最大加载位移的5%。这些为初始项目建议，不是文献保证；参考不确定度大于此量级时先限定结论，不能硬判精确通过。
独立参考要区分角钢扭转/弯曲/局部屈曲等未覆盖机制。轴向材料拟合优良不自动证明弹性弯曲支路足以替代空间纤维杆，必要塔段验证必须包括端部转动约束与轴弯传力。
适用域文件逐项记录截面/等级/长细比/边界/轴弯需求/循环范围和证据级别；`numerical_reference_only`与独立物理依据分开。N17/N18对关键杆实际状态逐项映射，未覆盖的非线性需求为`out_of_scope`。小塔段通过不构成整塔所有构造、材料和失稳机制的统一许可。

### F3. 峰值路径

现有45°位移控制采样峰值：裸塔λ≈30.78982、沿风位移≈0.30670m、沿风剪力≈1.33651MN；塔线λ≈29.37603、沿风位移≈0.30160m、沿风剪力≈1.31701MN。
对`U=20√λ`仅在λ≥0且同一参考气动/风速定义下解释；更改面积、系数、高度或网格后保持独立版本。裸塔达到X控制漂移1%，塔线只到0.8580%，不能把它当沿风1%或3%损伤阈值。
推覆步长建议峰值荷载差≤2%、峰值位移差≤5%；下降支的共同区间NRMSE≤5%只是路径一致性门槛，不是稳定性或物理正确性的证明。
相邻接受点发生突降时标出跳变/未解析区间；重算路径应从新鲜状态重放。CSV和节点位移不能恢复全部TMQ历史状态；不得将其当完整restart。
