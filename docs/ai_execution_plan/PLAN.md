## 5. 拟采用的数据契约与验收规则

### 5.1 配置与结果状态：先定义，再接入

T02 拟新增一个可序列化的配置对象，至少分开：

- `model`：源文件哈希、模型族、杆件映射、杆长分组、截面坐标/主轴、积分、缺陷形状/方向/幅值/种子。

- `boundary`：铰接/转动弹簧/6DOF 位移历程/塔段；边界历程文件指纹与施加方式。
- `protocol`：重力阶段、循环阶段、目标、次数、方向、物理时间或无量纲进度。
- `solver`：测试类型/容差/上限、算法及参数、最大/最小步长、恢复步长策略、失败上限。
- `calibration`：参考精度、取点方法、范围、状态变量、训练/验证工况标识、回退策略。

保留 RunManifest 的运行状态，不改变其既有语义；另加可独立查询的质量字段：

```json
{
  "execution_status": "completed",
  "coverage": {"requested_targets": 9, "completed_targets": 9},
  "validation_status": "unvalidated",
  "validation_scope": ["specified_monotonic_member_case"],
  "quality_flags": ["out_of_calibration_range", "local_response_mismatch"],
  "limit_state_status": "not_evaluated",
  "failure_reason": null,
  "eligible_for_fragility": false
}
```

这是拟定语义示例，不是现有 JSON 已有这些键。`completed` 不自动变成 `validated`。
历史无清单结果标记 `legacy_unknown`，默认不能进入新研究统计；可经人工/脚本复核后补建有来源的清单。
调试环境允许显式越界时保留结果和红色标记；正式统计使用 `out_of_domain` 拒绝策略，不能默默截平应变。

### 5.2 记录必须区分的坐标、状态和时间

最小标识：`run_id, model_id, original_member_id, segment_id, section_id, stage_id, cycle_id, direction, accepted_step`。
数值试算另有 `attempt_id, algorithm, requested_increment, accepted_increment, return_code, iterations`。

- 全局平动 m、转角 rad；局部 N/V 单位 N、M/T 单位 N·m；应变无量纲。
- 明确端部内力正负与杆轴；比较不同分段模型时投影到同一原杆参考轴，不能直接拼各段局部坐标。
- 准静力用协议阶段与单调进度，时间列不得伪装为物理秒；风振用真实 t，跨模型在共同 t 上比较。
- 已提交/已收敛数据与失败后 `trial_*` 数据必须分表或显式标记；失败值不得进入包络、损伤和拟合。
- 重力历程也要记录。将重力终点错误设为“零应力初态”会破坏局部边界重放。
- 关键杆记录两端各 6DOF、单元基本变形、完整端力、缺陷/弦长、中间节点形状；参考模型加截面曲率、纤维应力应变极值及屈服标记。
- 骨架状态记录 strain/force/tangent、所在段、分组键、加载方向、内部状态摘要、是否超范围。

### 5.3 误差怎样计算

单调曲线用已有 `ResponseCurve/compare_curves` 的共同区间与覆盖率。
往复曲线不能按位移全局排序、合并重复位移点；必须按 `stage_id + direction + stage_progress` 对齐。
位移控制阶段可用从起点到终点的归一化进度；零幅阶段单独处理，禁止除零。
对跳跃不能跨跳点插值得到“平滑精确”曲线，须同时比较跳跃前/后状态、发生区间与幅值。

每根关键杆至少报告：峰值压/拉力、目标点力、局部位移、卸载初始刚度、零力截距/零位移恢复力、
真实闭合协议的循环外功指标、最大纤维应变（参考）、首屈服/局部失稳标记及其定义。
全塔报告整体反力，也报告关键杆逐杆误差、P50/P90/P95/最大局部误差及空间分布。
不得只用全塔最大轴力作为所有杆件误差分母。参考响应接近零时用绝对容差并标明，不能制造巨大百分比或除零。

### 5.4 首版建议阈值（须在运行前冻结）

| 验收对象 | 建议阈值/规则 | 失败后 |
|---|---|---|
| 同实现纯弹性一致性 | 无量纲缩放后的力/刚度相对误差 ≤1e-6；刚体模态残差单独看 | 修坐标、标签、单位或参数 |
| 纤维/截面数值精度 | 面积误差 ≤0.1%；I22/I33/I23 相对有效尺度误差 ≤1% | 加密并保留耦合 |
| 局部参考 8→16 或必要时16→32段 | 峰力差 ≤1%，共同区间力曲线 NRMSE ≤2%，峰位移差 ≤2% | 继续局部加密，不全塔盲加密 |
| 步长/纤维加密 | 上述关键指标变化 ≤1～2%；跳点用发生区间而非强求同一步 | 冻结更细参考或标记不确定 |
| 峰前未屈服循环 | 零位移恢复力 ≤ max(1 N, 参考峰力×0.1%)；局部回线伪外功 ≤0.5% 的参考最大可恢复能量尺度 | 禁止进全塔 |
| 训练单调重构 | 峰力误差 ≤3%，局部 NRMSE ≤5%，比较覆盖率100% | 改取点/标定，不宣称独立验证 |
| 留出循环构件 | 峰力/刚度误差 ≤5%；局部曲线 NRMSE ≤10%；残余量/循环外功误差 ≤10%或约定绝对门槛 | 缩小范围或改模型族 |
| 塔段 | 初始刚度误差 ≤3%，整体反力 ≤5%，关键杆力误差 ≤10%，局部屈曲类别相同 | 返回局部机制 |
| 全塔 | 整体目标反力 ≤5%，关键杆 ≤10%；其余显著受力杆局部误差 P95≤10%、最大≤20%，所有超限有解释 | 不通过 G4，不能用总体均值掩盖 |
| 动力线性对照 | 前几阶目标频率误差 ≤3%；配对模态 MAC≥0.95（重根用子空间），小幅时程峰值/RMS误差 ≤5% | 查质量、刚度、阻尼与初始化 |
| 非线性试点风振 | 主要峰值/RMS误差 ≤10%，关键杆≤10%，越界/数值失败0个未解释 | 不扩批 |
| 缓存/状态/目录/单位 | 必须全部通过；不能以平均误差宽容工程错误 | 阻断后续 |

力学误差门槛必须结合参考自身误差和量级使用；若参考不稳定/多解，先报告分支和置信范围，不能套一个百分比。
屈曲后参考本身有真实残余时，不要求新材料回到零力。严格可逆性首先用纯Elastic钢材C0验证。
Steel02为光滑过渡模型，不能仅凭某一步应力小于fy就宣称严格弹性；C1先选远离屈服过渡的裕量
（例如max|σ_fiber|≤0.5fy作为试验起点），并核对参考自身的残余/循环变化后确定验收值。
近屈服循环应比较参考实际残余，不强求零力。
这些门槛不是通过调整参数事后挑选的目标；留出集在标定前冻结。

## 7. 最小实验矩阵与扩展规则

### 7.1 第一轮局部对象

| 对象 | 选择理由 | 第一轮必做 |
|---|---|---|
| 877、878 | 已定位卡点，空间镜像端部 | 两杆基线重放；877做完整收敛，878验证镜像差异 |

再增加1～2个不同细长程度的杆作为留出对象即可形成第一版适用域，不预先强制全部194组深度循环。

### 7.2 循环协议定义

采用参考模型测得的首次屈服/峰值位置定义幅值，不预设每根杆相同绝对应变。

| 协议 | 内容 | 验证目标 |
|---|---|---|
| C0 | 纯弹性钢材、很小幅正负与回零 | 数值/几何恢复、单位、载体状态 |
| C1 | 远离Steel02平滑屈服过渡的两级小幅压缩—卸载，每级3次；核对参考自身残余 | 避免原Hysteretic式虚假残余 |
| C2 | 接近参考峰值，部分卸载再加载、嵌套小循环 | 恢复刚度与历史变量 |
| C3 | 一个参考可靠峰后点→卸载→再压缩 | 峰后恢复/不可恢复机制 |
| C4 | 压缩→拉伸→压缩，幅值在参考有效范围内 | 拉压转换与塑性记忆 |
| C5 | 全塔真实两端6DOF历程，含重力和前序阶段 | 空间边界下有效性 |
| C6 | 标定时未用的幅值顺序/重复次数/边界 | 独立留出验证 |

最初用两组杆的C0/C1/C5确认参考；通过后再做C2/C3/C4。C6留作验收，不提前调参。
已有0→−0.0005→0协议可保留历史回归，但对不同钢级/长细比不应自动声称“全部弹性”。

### 7.3 扩展时遵循一次改变一个变量

1. 同边界、同材料，改变分段数；
2. 固定收敛网格，改变步长；
3. 固定以上，改变Fiber；
4. 固定参考精度，比较铰接与空间边界；
5. 再改变材料载体/循环法则；
6. 最后做方向、缺陷幅值、种子和风样本的留出验证。

若变量之间有强交互，明确新增一个小的交互矩阵，不直接扩成全参数扫描。
