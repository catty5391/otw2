## D02：SQLite证据保护核查

原快照纳入了SQLite的-shm和零字节-wal。读取旧数据库的并发客户端可能更新SHM中的共享读锁/读取标记，首次核查因此发现这类临时文件变化。
核查工具保留原始清单，不回写基准值，单独报告.sqlite-shm变化；数据库主体与WAL继续严格校验，非空WAL不能按临时文件忽略。
TowerInternalForceHistory读者同时改成mode=ro，避免普通读接口取得写权限。最终报告须注明核心文件与临时共享内存文件的区别。
