- **现有入口与陷阱**：`initial_imperfection_material/full_tower_cyclic.py` 已支持 `--target-drifts` 自定义目标序列和单模型/预算参数，可以提供单向递增目标的基础分析流程；它尚无“找到峰值后自动追踪极限”的语义、统一 capacity 报告或专用弧长包装。`pushover/pushover_main_with_buckling.py` 当前顶层直接循环11种缺陷比，且无 main guard；不能导入或直接运行来做单例，避免意外批算。正式实施应新增明确单例主入口或提取无副作用函数，并复用现有工程合同。
- **步骤1，冻结方案**：只选一个侧推方向、一个明确风荷载分布、一个缺陷 realization 和一个参考/候选模型。设定物理域上限、最大控制漂移、步长区间、节点/局部/全塔监测覆盖、峰值识别窗口与停止规则；不是根据已看结果挑最终最优配置。若需原向与反向，作为后续独立初态例，不混成同一“单调”曲线。
- **步骤2，记录与推进**：从重力后相对位移0开始，按预声明递增目标推进。基底剪力、控制位移、风载系数、全部施加自由度外功、平衡残差、每次尝试/拒绝/减步及阶段进度必记。关键6杆之外，若要声称“首根屈服/全塔屈服数量”，需增加全塔各杆所有相关积分点/纤维的稀疏事件扫描并核验覆盖；只记选定杆则图例明确限定。全塔分布图与局部事件同步，禁止用单个虚拟纤维坐标代表所有截面最不利点。
- **步骤3，终止分类**：区分 `target_reached_no_peak`、`peak_observed_postpeak_not_verified`、`peak_and_postpeak_covered`、`nonconverged_before_peak`、`nonconverged_after_observed_peak`、`out_of_validated_domain`、`budget_stop`、`equilibrium_failure`。峰值前数值失败只能给最后接受点及未知后续，不能称其为极限承载力；观察到局部V下降也须排除求解跳跃、加载路径/约束改变和记录错误。单调外功不是滞回耗能。
- **步骤4，峰后路径评估**：出现控制位移反转、显著负刚度或位移控制无法跟踪的证据后，才另评估弧长/其他路径跟踪；先查本机引擎接口和控制方程，再用已知极限点的小基准验证。当前不承诺已有 arc-length CLI 或一次就能追完整塔塌落。新增路径法须另立任务/预算，不在本轮失败后自动切换并把不同行进分支拼接成一条曲线。
- **输出**：独立未来批次的 `design.json`、monotonic_history.csv、全局V-u/相对初始线偏差/承载力变化图、局部失稳/名义fy事件表与覆盖、attempt/residual/domain审计、`CAPACITY_REPORT.md`。报告分别给“已计算最大点”“观测峰值”“经过验证的承载力”三个字段，后两者无证据即null。
- **验收**：重力起点可复现；全程单向加载历史真实；残差和适用域逐步检查；没有覆盖峰后时结论明确截止；正式峰值/峰位需满足已冻结的参考精度和另批同精度步长/网格检查，不能只凭单次完整运行认证。等效模型如出域，默认停止正式判读，探索性继续必须独立标注且不能进入易损性。
- **资源预案**：单例初次估计1～2小时、≤2GiB，硬上限7200秒/2500接受步/10000 attempts；实际目标范围与成本须在立项时重新估算。仅1例；上限耗尽交付partial及最后有效点，不自动追加方向、缺陷扫描或算法集合。此为未来独立任务额度，不叠加为本轮可以先开两个全塔。
- **失败分支与不得做**：继续保留可验证的预峰范围和未知极限；不因图像近直线就无上限放大荷载、不从循环末态接推、不运行11组旧脚本、不把不收敛前一点标倒塌、不未经门槛重扫风荷载样本。

## 5. 调度顺序与交接要求

推荐顺序为 M01→M02→M03/M04；M07-A、M08只读部分可在 M01 后并行。M05 只有证据需求明确时启动，且不与另一大型 FE 同机抢占；M06仅在有新依据时运行；M09/M10负责把可认证范围与待研究问题分开。M11为之后单独立项的单调承载力任务，先把当前图的物理意义和终止原因解释清楚，再安排计算。

每个执行人完成任务必须提交：实际步骤与命令、输入指纹、代码/配置差异、运行完成和覆盖、科学指标及门槛、失败/超时保留位置、结果图、下一项是否被解锁。新增实现的测试应验证字段映射、缺数据拒绝、提交/试算区别、范围证书拒绝越域，而不是只对照自己刚生成的数字。修改代码后做相关测试；最后集成做一次全仓测试，不因规划文件修改而重复上一批264项。

这里没有实施新代码、运行新增试验或更改任何研究门槛。上一批已有的587步全塔、三组877、825加密和前缀Fiber均应复用；本计划的首个可执行成果是既有记录的只读差异定位报告。
