## 1. 先回答曲线与屈服问题

当前完整四分段参考和fine等效算例都是九目标往复协议：±0.1%、±0.3%、±0.6%、±1%，最后回零。**它们在预设终点结束，没有计算超过±1%的继续加载。** 原步长等效算例才是6/9目标、约−117.775 mm因数值不收敛停止。见[全塔回归](../execution_20261022/TOWER_SOLVER_REGRESSION.md)。

因此目前既不能称“整塔都未屈服”，也没有获得整塔峰值承载力及峰后下降段。将来单调承载力试验必须从未加载初态与重力重新开始，不能接在已损伤的往复末态继续推，再称为单调曲线。

主 agent 本轮只读 `reference_legacy_v1/segmented_reference/cyclic_history.csv`，以第一段+0.1%数据拟合过原点的 `V=K0*u`，得到：

## 4. G1如何推进而不改变旧结论

- 已有877完整同四段重放相对端力误差2.15446%，仍是失败证据；原点映射、归一尺度和1e−6一致性判据保持可追溯。
- `acceptance_profile.json` 的1e−6字段名来自纯弹性一致性，已有局部工具也将其用于同网格重放。后续应明确该判据的使用范围、误差定义和非线性路径可比性，不能事后改阈值把已有失败改为通过。
- 825完整路径密采样峰力差0.7643%、峰位移差0.5659%只支持该路径该指标；原稀采样false结果继续保留。
- 前六目标端力/网格指标通过，不等于完整纤维精度通过，更不等于零载单调3%压缩参考通过。
- 范围化G1应列明杆号/边界/完整钢材/初态/缺陷/协议/位移范围/指标/网格和误差。完整G1保持原结论，另建范围证据，不把局部通过写回全局passed。
- 缩小范围必须有科学用途及事先声明的验证路径，不能只截取一段已经知道误差小的曲线当独立验证。申请不同范围需要额外验证，而不是重命名结果。

## 5. 单调推覆要单独解决的问题

F13新增的单调试验用于回答“是否出现整体明显非线性、峰值在哪里、停止由什么导致”，不预先要求画出下降段。

先检查荷载方向/分布、控制节点及位移、重力与P–Δ、约束、材料/屈曲机制和实际范围。选择一个方向、一个模型作为首例；保持与参考相同的身份记录。正负方向若都研究，分别从初态计算。不能将往复路径按位移排序拼成单调骨架。

新协议按小幅—已验证范围—条件扩展逐段推进。每一段进入前检查局部适用域、当前求解质量与剩余预算，记录切线/割线刚度、全局力、局部名义fy/侧弯、关键杆/主材响应和首次异常。等效模型越出标定域则停止正式比较，参考模型也受网格与钢材模型适用性限制。

若在尚未出现峰值时不收敛，结果只能是“在已覆盖位移前达到的最大力＋未确定极限”。若出现转折，先检查位移控制可否追踪该路径；需要弧长等方法时另建验证案例与接口，当前CLI没有该能力承诺。所有新方法必须区分失败试算和已提交状态。

首例完成后才决定是否补反方向或候选。单调峰值、往复退化和风振性能分别验收；不能因一条完整曲线把三者一起判通过。
