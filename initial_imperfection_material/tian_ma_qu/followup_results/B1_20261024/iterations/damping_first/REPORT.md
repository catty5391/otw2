# N04 阻尼与瞬态接口审计

本项已完成离线方案计算和源码审计，尚未验证实际动力阻尼；physical_validation=unvalidated。新FE=0。

## 实际步骤

1. 从已发布80段重力态模态与前三塔体匹配读取锚点，冻结仅供诊断的1%目标。
2. 计算三个候选C及逐阶谱，保存矩阵/构造指纹；没有在OpenSees中施加它们。
3. 用Python AST记录塔梁、导线、绝缘子单元语句及旧瞬态分析配置。
4. 编写后续适配规格与小扰动验收流程，输出科学图和CSV。

|方案|锚点Hz|最低导线模态候选阻尼|扭转 / X / Y候选阻尼|
|---|---|---|---|
|跨导线与塔体频带的候选|0.195077 / 2.505670|1.000%|0.865% / 0.920% / 1.000%|
|仅塔体频带锚点的敏感性对照|2.104214 / 2.505670|5.905%|1.000% / 0.996% / 1.000%|
|全局前两阶锚点的反例|0.195077 / 0.195089|1.000%|5.439% / 5.859% / 6.461%|

跨频带方案保留为N06数学参照候选；不能据此认定1%是该塔的真实阻尼。全局前两阶反例会给塔体频带更高阻尼；只锚定塔体也会增加低频导线阻尼。

线与绝缘子构造没有显式`-doRayleigh`，文档默认元素标志为0；节点质量比例项须另核，不能写成导线完全无阻尼。[官方杆单元文档](https://openseespydoc.readthedocs.io/en/latest/src/corotTruss.html)
Rayleigh各刚度选项和设置时机见[官方说明](https://opensees.github.io/OpenSeesDocumentation/user/manual/model/damping/rayleigh.html)。保存的重力切线K与`betaKInit`的初始元素K不是可互换名称。
