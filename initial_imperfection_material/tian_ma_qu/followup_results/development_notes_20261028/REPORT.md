# 当前新材料：实现、公式、参数缺口与识别路线

核对日期：2026-10-28。本说明以当前代码及已保存的全塔参数表为准。此次整理不替换全塔材料参数。

**当前已实现的是构件级 Tian–Ma–Qu 分段滞回原型；不是把 Steel02 的钢材公式改写，也不是已经复现了新上传论文中的角钢 PHM。它能运行完整往复加载，但本塔角钢循环参数尚未完成试验验证。**

## 1. 到底开发了什么

| 层次 | 当前实现 | 作用与范围 |
|---|---|---|
| 本构与历史 | `tian_ma_qu/material.py`，`TianMaQuPrototype` | Python 计算应力、切线刚度、转折点、历史极值、承诺/回滚状态；自行管理循环支路 |
| OpenSees 接口 | `native_bridge.cpp`、`opensees_adapter.py` | C++ 单轴材料接口把 OpenSees 的 trial/commit/revert 调用交给 Python；实验性 Linux/CPython/OpenSees 3.8.0 接口，不是官方内置材料 |
| 截面接口 | `section_adapter.py` | 将构件等效应力转换为轴力 P=Aσ，轴向刚度为 AEt；弯曲、扭转使用独立弹性分量 |
| 全塔 | `model/tower_model_with_tian_ma_qu.py` | 每根物理杆采用一根直的 Corotational `dispBeamColumn`、3点 Legendre 积分；保持空间几何非线性 |
| 参数与试验 | `cases.py`、识别模块、结果目录 | 钢管文献参数演示 → 有序试验历史检查 → 分组条件识别 → 尚待角钢验证 |

现在全塔的轴向压屈折算在构件本构中，不再对同一杆额外施加杆内初弯曲。截面中轴力与弯矩不耦合，弯曲使用 EI22、EI33，扭转使用 GJ（G=E/2.6），未计 I23 弯曲耦合。首压峰计算用的是最小主轴惯性矩，二者不要混淆。

旧方案是四分段、有几何初弯曲的 Steel02 纤维梁，包含弯曲与轴力耦合；新旧对照必须称为“两种建模方案对照”。相同风荷载下出现响应差异，不能全部归因于材料系数。

## 2. 当前代码实际使用的公式

### 2.1 变量及拉伸支

拉伸为正、压缩为负。L 为初始物理杆长，A 为截面面积：

```text
ε = ΔL / L                  σ = N / A
εy = fy / E                 s1 = −φ fy
首次拉伸：σ = E ε                              （ε ≤ εy，拉伸支）
拉伸强化：σ = fy + ρ E (ε − εy)                 （ε > εy）
```

这里 ε 是整根杆的等效轴向应变，包含被折算的构件变形效应，不能直接作为钢材纤维塑性应变或套用原纤维断裂阈值。当前初始受压支同样是直线 E；没有沿用早期 Perry 等效材料的非线性弹性几何缩短公式。

### 2.2 首次受压和后续受压

初始曲线取反转参考点 R=(0,0)；从拉伸强化支反向压缩时，取当时的 R=(εR,σR)，生成新的压缩曲线。

```text
ε0 = εR − σR/E
sk = s1                     （尚未进入过压屈下降支）
sk = η s1                   （已经进入过压屈下降支）
εc = ε0 + sk/E

(a,b) = (α,β)               （首次下降支）
(a,b) = (θ,κ)               （后续下降支）
εd = εc + (1−γ) sk/(aE)
εt = εd + (r−γ) sk/(−bE)

σ = E(ε−ε0)                 （ε ≥ εc，压缩加载的弹性段）
σ = sk − aE(ε−εc)           （εd ≤ ε ≤ εc）
σ = γsk − bE(ε−εd)          （εt ≤ ε ≤ εd）
σ = r sk                    （ε ≤ εt，尾部延伸）
```

α、β、θ、κ按正数输入；下降支的切线为负。r 是额外的残余承载力比例，当前默认 0。尾部延伸不等于杆件断裂或单元删除。当前每个后续压峰都取 η×首峰，既不是 η 的循环次方，也没有按累计塑性应变递减。

### 2.3 压屈后的卸载、捏拢与恢复拉伸

由压缩下降支或尾部反向时，以实际反转点 R 建立拉伸曲线。Ehist 的两个端点是“历史最大/最小应变处的应力”，不是全历史最大/最小应力：

```text
Ehist = [σ(ε历史最大) − σ(ε历史最小)] / (ε历史最大 − ε历史最小)
Ku = τ Ehist               Kp = μ Ehist               Kr = ν Ehist
εG = εR − σR/Ku
εH = εG + ζ fy/Kp
εI = εH + (1−ζ) fy/Kr

σ = σR + Ku(ε−εR)          （R → G，压缩卸载至零力）
σ = Kp(ε−εG)               （G → H，拉伸捏拢段）
σ = ζfy + Kr(ε−εH)         （H → I，恢复至拉屈服）
σ = fy + ρE(ε−εI)          （I 之后，拉伸强化）
```

只有弹性加载、尚未实际进入压屈下降支时，反向沿弹性路径恢复。仅碰到首压峰不触发压屈后卸载规则。未完成大循环的局部反转，目前沿所在分支返回其起点，再恢复父分支；这是项目补充的闭合规则，尚未完成实验验证。

材料为率无关模型。每次 trial 从承诺状态复制，迭代失败可回滚，不应按迭代次数累积损伤。记录的绝对应变累积量目前不驱动退化；积分 ∫σdε 是有符号外功，只有在相应闭合回线及一致能量口径下才可讨论滞回耗能。

### 2.4 全塔首压峰 φ 怎样得到

当前按每根实际杆件的 E、fy、A、L、最小主轴惯性矩 I 及外缘距离 c，采用初弯曲 e0=L/1000、有效长度系数 K=1 的 Perry 型首次纤维屈服条件：

```text
NE = π² E I / (KL)²
e(N) = e0 / (1−N/NE)
N/A + N e(N) c/I = fy
φ = N / (A fy)
```

这里 N 为压缩正幅值，使用二分法求解；代入 TMQ 后压峰应力取负。该条件对应“最外缘首次达到 fy”的近似荷载，并未证明它就是构件极限承载力。K、缺陷和端部偏心的实际依据仍需核查。

## 3. 全塔现在实际用了哪些参数

核对对象为 `tower_results/tmq_bounded_03/model_data/tmq_member_parameters.csv` 的 1528 根物理杆。以下是当前参数来源，不是本次新增拟合结果。

| 参数 | 当前全塔数值 | 现有来源 / 缺口 |
|---|---:|---|
| E | 210 GPa | S2K 工程输入；不是本塔同批券样实测 |
| fy | 235 / 345 / 420 MPa | S2K 钢材等级；604 / 728 / 196 根 |
| A、L、I、c | 按实际杆件 | 截面与原始节点；实际连接长度、偏心尚需核实 |
| φ | 0.130985～0.944629 | 按上式逐杆生成，287 个不同值；不是角钢试验反演 |
| ρ | 0.03 | 继承全塔强化配置；不是当前试验识别值 |
| α、β | 0.506、0.020 | 文献 P102 钢管表格 A 行，暂借用于角钢 |
| γ | 0.5 | 转折比例假定 |
| τ、μ、ν | 1.449、0.474、1.549 | 同一钢管参数行，尚无本塔角钢依据 |
| ζ | 0.1 | 拉伸捏拢转折比例假定 |
| η、θ、κ | 0.544、0.020、0.0044 | 同一钢管参数行；常数后续峰的适用性未通过完整验证 |
| r | 0 | 项目尾部闭合假定，不含断裂 |

因此不是“参数没有填，所以算不了”，而是“数值已经填齐，角钢适用依据还没有齐”。不能把演示钢管的 E=206 GPa、fy=327.28 MPa、φ=0.797、ρ=0.01 误认为本塔配置。

## 4. 已经做过的参数识别，实际得到什么

Carden P/Q 使用作者有序绘图路径，共 9589 个顶点；它们不是带采样时间的仪器原始记录。固定实测券样 E=218 GPa、fy=338 MPa，但面积和长度仍采用报告名义值，位移还涉及作动器/夹具口径。

| 项目 | 结果 | 是否可直接替换本塔参数 |
|---|---|---|
| 首压 φ | 0.720582 | 否，仅该试件和当前归一化条件 |
| 首压下降 α、β | 0.092127、0.029319 | 条件候选，需结合首峰位移失配审查 |
| 卸载 τ、μ、ν | 6、0.7、3.47094 | τ、μ碰搜索上界，不能当作稳定识别 |
| 拉伸 ρ | 0.00281948 | 后续拉伸支的条件识别，不是钢材券样强化比 |
| 后续 η、θ、κ | 未接受 | 灵敏度秩仅 2/3，κ 无敏感性，θ碰下界 |
| 完整回线 NRMSE | P 36.77%，Q 32.19% | 完整回线未通过；这是当前候选，不是所有 TMQ 的最佳可能误差 |

首峰观察缩短约 1.869 mm，当前模型约 0.721 mm，需先检查标距、几何柔度及夹具。P 的后续压峰从首峰的约 0.701 逐渐降到 0.505，当前固定 η 无法同时匹配全部峰值。扩大遗传算法范围不会自动修正这两类机制问题。

已有完整回线与诊断：[Carden 页面](../carden_conditional_20261026/index.html)。如果已看过 Q 后又依它改模型，Q 就不再是下一阶段未见过的独立验证集。

## 5. 缺什么，怎样分组确定

| 顺序 | 固定条件 / 必须取得的数据 | 识别对象与办法 | 接受条件 |
|---|---|---|---|
| 1. 数据准入 | 有序力—位移、尺寸、标距、券样 E/fy、端部约束、预加载与单位 | 对真实历史保留顺序；扫描散点只当特征；先拉屈服后的压峰不得冒充 virgin 首峰 | 来源、符号、顺序和初始状态可追溯 |
| 2. 首次压缩 | 固定 E、fy、几何及标距 | φ=首峰幅值/(Afy)；α、β由下降段斜率/E识别，γ由转折位置约束 | 首峰荷载及位移均检查；缺少第二下降段就不识别 β |
| 3. 卸载和再加载 | 真实压后卸载、零力穿越和恢复拉伸 | τ=Ku/Ehist、μ=Kp/Ehist、ν=Kr/Ehist；ζ由转折应力/fy约束 | 刚度、零力残余位移、捏拢和恢复段同时匹配 |
| 4. 拉伸强化 | 实际超过拉屈服的支路 | ρ=Et/E；区分构件强化和券样强化 | 只有弹性段时保持“未识别” |
| 5. 后续压屈 | 多个幅值、至少多个可辨认后续压峰和下降支 | η由后续峰/首峰约束，θ、κ由后续下降支约束；先检查常数η能否成立 | 报告各循环误差；不成立则修改机制，不能只调系数 |
| 6. 受约束联合细化 | 冻结训练/留出试件，保留完整因果历史 | 小参数组 GA 多起点＋局部优化；分支/试件平衡权重；峰值、斜率、回线和残余联合目标 | 参数不持续撞界，灵敏度与秩支持可辨识；报告范围/不确定性 |
| 7. 独立验证与接塔 | 新留出构件 → 实际塔杆族 → 塔段 | 弹性恢复、小反转、完整循环、模态/静刚度、推覆及失稳次序 | 单调曲线拟合或优化器收敛不能代替独立验证 |

本塔 Q235/Q345/Q420、26 种截面及连接条件不能由一个试件覆盖。有效长度、初始缺陷、端部连接属于构件条件，需要分组；全部杆件共享一组钢管循环参数只能保留为演示/敏感性基线。

另缺经过验证的小反转规则、超出标定应变范围的处理、历史相关退化及疲劳/断裂证据。这些是模型机制和适用域问题，不能都归为“还缺几个待拟合数字”。

## 6. 新上传的角钢 PHM 能提供什么

2023 年 Liu–Tian–Ma–Meng 的固定端等边角钢 PHM 使用非线性下降段、非线性恢复段及历史塑性应变相关退化。它尚未替换当前 `TianMaQuPrototype`。例如其后续压峰关系为：

```text
λn = (KL/i_min)/π × √(fy/E)
θPHM = (1 + 69.896 λn εp)^−1.566
|Ncr,后续| = θPHM |Ncr,首次|
```

εp 是历史最大塑性应变，须按论文核实定义和更新；不能直接用循环次数或累计绝对应变替代。新论文 κ 对应拉伸强化，含义接近当前 ρ；新论文 θ 对应峰值退化，绝不是当前代码的第二组下降斜率 θ。不能直接复制同名希腊字母的数值。

建议先以 2023 英文角钢论文为独立实验分支，解决下降公式的符号/量纲、再加载系数、失效终点及小反转定义，恢复一个完整真实试件，再评估本塔角钢覆盖。固定端角钢论文不能自动证明现有塔节点连接等同固定端；新 PHM 的初始压缩仍为直线，也不自动解决 Carden 首峰位移差。

新增五篇文献的逐项核查：[文献与公式对照说明](/download?key=tmq-angle-literature)。原模型：Liu et al., JBE 46:103798，DOI 10.1016/j.jobe.2021.103798；角钢模型：Liu et al., TWS 183:110335，DOI 10.1016/j.tws.2022.110335。

## 7. 来源等级及本次执行记录

当前 2022 TMQ 公式来自公开第三方全文转写和已有论文对照，尚未取得其出版社完整原 PDF 或作者源代码。代码显式保留三项解释：压缩下降斜率取负；GH段起点采用 εG；重复区间按末下降区间解释。2023 角钢 PHM 则已读取用户提供的完整 PDF，两者来源等级不能混写。

本次按顺序核对：材料分支与状态 → OpenSees桥接及截面 → 全塔参数CSV → 已有真实历史识别结果 → 新论文与当前字段差别 → 以上分组识别路线。没有将文献回归曲线冒充本项目新试验，没有将未通过的候选参数写入全塔。

与本说明同时执行的新旧模型风荷载对照，覆盖单塔、塔线与 0°/30°/45°/90°，另有独立运行报告。它检验当前两种方案在相同输入下的响应差异，不构成 TMQ 参数已获实验验证的证据。
