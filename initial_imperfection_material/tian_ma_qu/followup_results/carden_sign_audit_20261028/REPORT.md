# Carden 拟合曲线偏左：符号、坐标与恢复支审计

日期：2026-10-28。审计对象是已有 Carden P/Q 条件拟合及追加 ρ 细化结果，不涉及新曲线本构开发，也未重新拟合参数。

**在“原 PDF → 矢量坐标 → 单位转换 → TMQ 输入输出 → 已保存绘图数组”链条中，没有发现拉压符号颠倒。用户看到的偏左确实存在：后续反向拉伸恢复支过早达到高拉力，而且偏差随循环增长。另查出 Q 试件原点说明的元数据错误，已更正生成代码并给旧报告追加注记，原数据保留。**

P 试件第二次、第九次正向恢复支达到同一拉力 **0.9Afy** 时，预测位移相对观察分别为 **−14.156 mm、−75.241 mm**（负数表示偏左）。初次受压峰却相反：预测峰约在 −0.721 mm，观察为 −1.869 mm，说明不能用整体翻号或横向平移修复。

## 1. 独立复核了什么

1. 直接打开 MCEER-08-0002 原 PDF 第101页（印刷71页）图3-24、3-25，目视核对坐标轴：位移向右为正，轴力向上为正。
2. 通过 PyMuPDF 独立渲染器读取实际线段，逐线段对照缓存的原始 PDF 命令。P 的5354条、Q的4162条非零绘图线段全部对应，最大屏幕坐标差分别为 0.0000317、0.0000352 PDF 点，属于浮点舍入。
3. 读取原矢量命令的局部矩阵：两图均为 `[1,0,0,1,tx,ty]`，只有平移，没有镜像或旋转。PDF原始y坐标向上；屏幕坐标向下由页面矩阵处理，不应再把原始力坐标取负。
4. 独立按横向6 in/313.2 PDF点、纵向50 kip/193.92 PDF点换算。9589个点与已保存CSV的位移、观察力逐点差均为0；作者顺序和重复点均保留。
5. 按当前发布的参数重放全部历史，预测与 `P_refined_predictions.csv`、`Q_refined_predictions.csv` 逐点差为0。P初次位移为负、Q初次为正，分别对应先压、先拉。
6. 提取每个正向加载支达到同一拉力的位置，并检查材料内部 F/G/H/I 转折点，分开识别坐标问题和恢复规则问题。

## 2. 为什么不是绘图时整体移到了左边

现有图的黑线与橙线共用完全相同的横坐标数组：

```text
u = 作者原始位移序列
ε = u/L
σ = TMQ(ε, 历史)
N = Aσ
绘图：(u, 观察力) 与 (u, 预测力)
```

没有给预测曲线另外减位移常量，没有按位移大小重新排序；两模型/观察的起点均按路径首点归一为 `(0,0)`。曲线某一受力水平出现水平偏差，含义是在同一位移历史下，模型的力恢复过早或过晚。

这里的横轴是作动器位移；输入应变是作动器位移除以名义杆长，尚未独立扣除夹具和连接柔度。这一口径问题仍会影响拟合，但不属于正负号错误。

## 3. 偏左有多大

选用共同力水平 `0.9Afy=66.697 kN`。下表沿原有序正向支寻找首次跨越，并仅在相邻保存点间插值；不外推未达到该力值的末端损伤支。

| 试件与正向支 | 观察达到该力的位移 / mm | TMQ位移 / mm | 模型−观察 / mm |
|---|---:|---:|---:|
| P，第1正向支 | 2.955 | 2.571 | −0.384 |
| P，第2正向支 | 7.941 | −6.215 | −14.156 |
| P，第5正向支 | 26.626 | −12.515 | −39.141 |
| P，第9正向支 | 51.391 | −23.850 | −75.241 |
| Q，第1正向支（初次受拉） | 2.219 | 0.900 | −1.319 |
| Q，第2正向支 | 6.540 | −2.055 | −8.595 |
| Q，第7正向支 | 37.954 | −13.250 | −51.204 |

因此“恢复支偏左”的观察是准确的，而且不是一个固定平移量。完整逐支表见 [recovery_crossings.csv](recovery_crossings.csv)。P、Q的最后正向支有试验末端失强，观察没有达到0.9Afy，表中保留空值；没有为了减少误差删除这些点。


## 4. 首压峰恰好是另一个方向的偏差

P首压观察峰为 −53.401 kN，位于 **−1.869 mm**。以当前 E、fy、φ、L 建立的线性初始压缩支，理论拐点位于 **−0.721 mm**；原CSV采样到的最负预测点为 −0.817 mm，不能把采样位置等同精确拐点。

```text
u_cr = −φ fy L / E
观察峰相对线性理论多出的缩短 = 1.148 mm
```

所以初压理论峰相对负位移的试验峰反而偏右。统一翻号或把整条曲线平移，不能同时解决初压峰和后续恢复支的方向不同、幅值不同的偏差。α、β主要改变下降支，也不能独自改变固定E、fy、φ、L决定的初压峰位置。

这只能说明当前端部位移口径与线性构件初始刚度不能同时重现该峰位；几何柔化、端部/夹具柔度、真实标距等原因还需逐项核实，不能据此直接降低实测钢材E。

## 5. 恢复支为什么越来越早升到高拉力

当前代码从压缩反转点 F 建立：

```text
Ku = τ E_FB       Kp = μ E_FB       Kr = ν E_FB
εG = εF − σF/Ku
εH = εG + ζfy/Kp
εI = εH + (1−ζ)fy/Kr
```

本次参数仍为 τ=6、μ=0.7、ν=3.47094、ζ=0.1，其中τ、μ是在第一条卸载/恢复支拟合时碰到搜索上界的候选。后续压屈参数 η/θ/κ 并未完成识别，仍使用先验，尾部残余承载力比例为0。

逐状态检查发现：P第5次大压缩反转（约−32.232 mm）开始，模型已经走到零残余压缩尾部。到第9次反转时：

| 模型状态 | 位移 / mm | 轴力 / kN |
|---|---:|---:|
| F 压缩反转 | −58.040 | 0 |
| G 恢复至零力 | −58.040 | 0 |
| H 捏拢段终点 | −44.958 | 7.411 |
| I 恢复至名义拉屈服 | −21.212 | 74.108 |

此时历史割线模量 E_FB≈2.381 GPa。由于反转点已经被尾部规则置为零力，G直接落在F；后续分段斜率和转折点又使其仍处于约21 mm净缩短时就达到名义拉屈服。观察曲线达到更低的0.9Afy还需要走到 **+51.391 mm**。

这定位的是**当前模型的恢复支形状、转折点/历史更新与零残余尾部组合的失配**，不代表现有试验已经唯一识别出一个修复公式。仅把折线画得圆滑，也不自动保证恢复位置正确；新曲线本构必须一起验证恢复零点、H/I位置和历史塑性伸长。

## 7. 发现并修正的真实问题：P/Q原点说明混写

独立读取原图实际零轴后得到：

| 试件 | 路径首点相对水平零轴的原始力坐标 | 约合轴力 | 是否超出一条0.543pt线宽 |
|---|---:|---:|---|
| P | +0.24 PDF点 | +0.275 kN | 否 |
| Q | −0.96 PDF点 | −1.101 kN | **是** |

两图路径首点的x与实际垂直零轴重合到PDF浮点精度。旧说明中的约0.12点横向差源于整幅标尺对称拟合/舍入；不能混同实际垂直零轴偏移。

旧代码给P/Q统一记录0.24点纵向偏差，并称都在一条线宽内，这对Q不成立。当前已有数值是**把作者路径首点作为零力**，没有按照绝对图轴补上述偏置。二者的关系是：

```text
F_相对实际图轴 = F_当前路径归零 + δF
P：δF≈+0.275 kN；Q：δF≈−1.101 kN
```

已经更正 `carden_ordered_experiment.py` 的原点说明、未来生成的分试件元数据及报告生成模板。旧数据清单、矢量顶点、CSV、拟合系数及图片均保留；旧报告追加此项更正，避免让读者误认为历史结果被悄悄重算。还没有仪器原始零点依据，因此没有把另一种归零方案替换成“已证实正确”的数据。

本报告CSV也列出采用图轴力零点时的0.9Afy位置，便于检查这个有限纵向偏差的影响；它不能解释随历史增长的14～75 mm水平偏移。
