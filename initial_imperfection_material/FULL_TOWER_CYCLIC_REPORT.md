# Z30103A6 全塔往复加载试验报告

> 2026-10-21 补充诊断：本页保留原步长设置的历史结果。原 −117.775 mm 卡点已定位到
> 877、878 号杆在下降段回程折点附近的局部分支跳转；保持材料不变、允许进一步缩步后，
> 可完成全部 9 个目标。但这些杆在 −0.6% 时的局部轴力与参考相差约 79%，
> 在 −1% 时等效压应变约 4.103%，超出 3% 标定范围。
> 本页整体误差指标不代表局部失稳行为已验证，详见
> [CONVERGENCE_DIAGNOSIS.md](CONVERGENCE_DIAGNOSIS.md)。

## 1. 试验目的

本轮不再停留在单杆或小塔段，而是将构件级初缺陷等效本构直接接入
Z30103A6 全塔，与现有分段几何初缺陷模型进行准静力往复对照。重点检查：

1. 全塔初始刚度和各级目标点基底剪力能否保持一致；
2. 全塔1528根物理杆件的轴力空间分布能否保持一致；
3. 大幅反向加载及回零路径是否仍然可靠；
4. 等效方法能否降低全塔分析成本。

本报告对应 `results/full_tower_cyclic` 中的正式计算结果。

## 2. 模型与接入方式

### 2.1 分段几何初缺陷对照模型

- 每根物理杆分为4个 `dispBeamColumn`；全塔共6112个梁段；
- 使用可复现的随机缺陷方向，随机种子为30103；
- 杆内节点按半正弦曲线布置，最大初弯曲为 `L/1000`；
- 材料为 `Steel02`，几何变换为 `Corotational`；
- 本轮为控制计算规模仍采用4段，因此它是现有全塔模型的工程对照，不能替代
  8段或16段全塔网格收敛验证。

### 2.2 等效初缺陷全塔模型

- 保留1528根物理杆，不再设置杆内几何缺陷节点；
- 按“截面名称＋1 cm杆长分组”建立194组构件骨架；
- 每组优先使用16段单杆参考模型、120步、最大3%缩短进行离线标定；
- 193组完整收敛并采用参考标定；`L40x3Q235-L1.95 m` 组只完成5/120步，
  因此明确回退到 Perry 骨架。该组对应原塔杆825、828、917、920；
- 每根物理杆拥有独立材料状态，分组只共享骨架数据，不共享 OpenSees 材料对象；
- 等效应力—应变先乘实际截面面积，转换为截面 `P` 通道所需的
  轴力—轴向应变；
- 梁截面保留弹性 `My`、`Mz` 和 `T` 通道，几何变换仍为 `Corotational`。

这里没有采用纯 `corotTruss` 全塔。试算表明，原 S2K 塔的部分稳定性依赖杆件
弯曲及节点转动连续；直接换成理想铰接桁架会产生平动机构，也会把“更换材料”
扩大成“更换结构体系”。

## 3. 加载协议与记录内容

重力分10步施加并保持，随后沿全塔既有风荷载分布在全局 Y 方向进行位移控制。

- 控制节点：350；
- 控制高度：36.4 m；
- 基底节点：2510、2511、2512、2513；
- 目标漂移比：`+0.1%、-0.1%、+0.3%、-0.3%、+0.6%、-0.6%、+1.0%、-1.0%、0`；
- 常规位移步长：5 mm；遇到不收敛自动缩小到0.3125 mm；
- 每个收敛步记录控制点位移、基底剪力、荷载系数和全塔单元内力。

准静力数据库中的 `time` 使用单调递增的协议步号，不使用反向变化的荷载系数，
因此仍可按任意记录时间段查询内力历史、快照和包络。

## 4. 主要结果

| 指标 | 等效模型 | 4段几何初缺陷对照 |
|---|---:|---:|
| OpenSees单元数 | 1528 | 6112 |
| 完成目标点 | 6/9 | 9/9 |
| 完成分析步 | 272 | 587 |
| 全塔计算时间 | 334.17 s | 855.12 s |
| 正向已完成峰值基底剪力 | 979.27 kN（+0.6%） | 1624.77 kN（+1.0%） |
| 负向已完成峰值基底剪力 | -975.74 kN（-0.6%） | -1616.49 kN（-1.0%） |
| 最终状态 | +1.0%目标途中停止 | 成功回到零位移 |

等效模型完整完成了正负0.1%、0.3%和0.6%三级循环。在由-0.6%转向+1.0%的
回程中，计算到相对重力状态位移 **-117.775 mm**、基底剪力
**-526.86 kN** 后，即使步长缩至0.3125 mm并切换 Newton、KrylovNewton 和
NewtonLineSearch，仍无法继续。

分段模型完成全部目标并回到零控制位移。此时基底恢复力约为 **3.90 kN**。
由于终点是强制位移回零，这个数值是零位移处的恢复力，而不是自由卸载后的残余
位移。

## 5. 共同有效范围内的精度

为避免把等效模型未完成的+1%路径与对照模型完整路径混在一起，误差仅统计双方
均完整完成的前6个目标点，即截至-0.6%漂移、两者均为第251步。

- 6个目标点的最大基底剪力误差：**0.321%**；
- 对1528根物理杆轴力绝对值包络进行比较：
  - 相关系数：**0.999964**；
  - 以对照模型最大轴力归一化的 RMSE：**0.141%**；
- 等效全塔运行时间约为分段模型的 **39.1%**，即本算例约快 **2.56倍**；
- 首次生成194组标定库另需约169.50 s，后续重复分析可直接复用缓存。

这说明等效模型在其可收敛范围内，不仅整体侧向反力接近，杆件轴力空间分布也
高度一致。当前主要问题不在峰值或弹性刚度，而在大幅反向加载后的路径连续性。

## 6. 力学解释与适用边界

当前默认载体 `ElasticMultiLinear` 是可逆的多折线非线性弹性材料。它解决了
屈服前卸载产生虚假残余力的问题，但不能表达分段梁模型中的以下机制：

- 初弯曲形状随卸载和反向加载连续演化；
- 多根压杆依次屈曲时的模态转换和内力重分布；
- 钢材屈服后的真实卸载刚度与塑性记忆；
- 下降段附近可能出现的极限点、分岔和跳跃路径。

因此，本轮结果支持以下两条不同强度的结论：

1. **在正负0.6%漂移以内**，等效模型可以较好重构本算例的整体反力和物理杆轴力
   包络；
2. **不能据此把它直接用于任意强度的风振或倒塌往复分析**。在本协议中，它未能
   完成由-0.6%转向+1.0%的路径，而分段模型完成了全部循环。

此外，4段全塔对照仍包含已知网格误差。本轮比较的作用是验证“直接接入全塔后
会发生什么”，不是宣布4段模型已经成为最终基准。

## 7. 下一步修改方向

1. 对4根 `L40x3Q235-L1.95 m` 杆单独提高参考模型路径跟踪能力，避免 Perry
   回退对全塔平衡路径产生离散跳变；
2. 将单调下降段改为带正则化的循环规则，至少保证卸载方向能够连续通过骨架折点；
3. 对全塔增加弧长法或能跨越极限点的路径跟踪试验，区分“材料路径错误”和
   “真实整体分岔”；
4. 选择关键幅值进行8段全塔复算，评估4段对照的离散误差；
5. 完成上述工作后，再将材料用于脉动风时程和易损性批量分析。

## 8. 复现命令与输出

```bash
uv run python -m initial_imperfection_material.full_tower_cyclic
```

主要输出：

- `results/full_tower_cyclic/base_shear_displacement.png`：全塔往复曲线；
- `results/full_tower_cyclic/target_comparison.csv`：共同目标点反力误差；
- `results/full_tower_cyclic/axial_force_envelope_comparison.csv/png`：物理杆轴力包络；
- `results/full_tower_cyclic/summary.json`：模型、收敛和误差汇总；
- 两个模型目录下的 `tower_internal_forces.sqlite`：逐步全塔内力数据库；
- `calibration_library.json`：194组构件骨架及标定状态。
