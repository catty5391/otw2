# 全塔位移控制推覆

独立实验模块，比较单塔 Steel01/Steel02 四分段初弯曲方案与 Tian–Ma–Qu 整杆等效方案；采用共同重力、参考节点风荷载及控制位移计划。默认 0°、30°、45°、90° 共12例，目标为350号节点位移/36.4m=3%。这只是计算范围，不是损伤等级。

- Steel01/Steel02：4段、半正弦L/1000、随机种子30103、17纤维、6点Legendre、Corotational dispBeamColumn。材料完整参数随结果归档。
- TMQ：1根直线等效梁、3点Legendre，轴向TMQ与弹性弯扭，避免重复计入初弯曲；仍有角钢参数未独立验证，不能视为只更换钢材本构。
- 先施加10步重力；0°/30°/45°控制全局X，90°控制Y。同时记录350节点沿风位移及真正39.6m塔顶平均位移。
- 增量2/5/10mm按50/200mm分界；Newton、NormUnbalance(0.005,40)，**首个失败增量即停**，不切算法、不缩步重算、不放宽容差。单独区分时限停止。
- 每个已接受状态保存所有物理杆的端力/弯矩和纤维包络或TMQ状态、原始节点六自由度、分层变形、支反力和平衡残差；重点8杆保存无载→重力→推覆完整端部历史。

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 .venv/bin/python -m initial_imperfection_material.tower_material_pushover.experiment --output /tmp/new_tower_pushover --angles 0 30 45 90 --case-budget 3600 --jobs 2
.venv/bin/python -m initial_imperfection_material.tower_material_pushover.publication --output /tmp/new_tower_pushover
.venv/bin/python -m unittest tests.test_tower_pushover_evidence tests.test_tower_material_pushover -v
```

原始结果不得覆盖；复算使用新目录。每例代码快照和哈希保存在`runs/<case>/code_snapshot/`。网页入口为 [全塔位移控制推覆](http://localhost:9999/tower-pushover/)，也可从首页→单塔分析进入。

`results/REPORT.md`详细列明步骤、实际曲线、首次材料事件、停止问题、输入一致性审计和后续易损性使用范围。`damage_candidates.json`只保存观测证据，不指定等级。非收敛、末点、采样最大值和真实极限状态必须区别；没有下降支时不能外推峰后界限。

这是静力加载历史，step不是物理时间。原始大数据保留本地，不自动提交上传。

## 2026-10-29 本轮实际结果

12个工况均完成本轮尝试，并在第一次Newton不收敛时停止；没有一例到达预定3%控制位移比。最后收敛位移如下，单位mm，括号为首失败目标：

|风攻角|Steel01四段|Steel02四段|TMQ整杆等效|
|---|---:|---:|---:|
|0°|520（530）|520（530）|380（390）|
|30°|360（370）|360（370）|260（270）|
|45°|300（310）|300（310）|220（230）|
|90°|350（360）|440（450）|260（270）|

0°钢材方案已出现明确非线性：Steel01首次名义纤维屈服区间为(310,320]mm，Steel02为(340,350]mm；均首先在346号杆观察到。两者470mm处采样峰值分别2118.31/2119.04kN，520mm末点降幅5.43%/4.80%，均未跨过峰后80%。

0°TMQ已接受曲线仍近线性，末点380mm／1797.29kN；1528杆的材料状态仍均为elastic。388/390号杆达到各自本构首压阈值的约97.686%，390mm失败步出现范数振荡。缺少失败试探材料状态，尚不能确定失稳杆或证明分支切换就是失败原因。它的末点不能视作容量极限。

三方案共同380mm处剪力为1788.71、1786.96、1797.29kN，相差不足0.6%；不得用TMQ截断末点直接对比钢材已观察到的峰值。其他角度完整的共同位移范围比较见`results/common_range.csv`。

TMQ在30°、45°、90°分别于(120,125]、(75,80]、(90,95]mm首次观察到材料压屈，末点压屈杆数分别1、12、2。该事件不等同于钢材方案的纤维名义屈服。

共保存847个风荷载增量、859个平衡状态。各角度三方案的原始几何、物理杆参数、节点质量、支承和节点风荷载哈希均一致。859点的独立全局合力/合矩复核全部通过，最大残差约9.47×10⁻⁵N、2.47×10⁻³N·m；39项相关自动化测试通过。数值平衡不等于试验验证。

原始计算数据约0.8GB，留在本地。每例停止详情在`results/issues.json`；网页和报告列出步骤、实际前缀、算法与范数。正式运行包含资源争用和临时进程调度等待，墙钟耗时不可直接用于新旧方案速度比较。

后续优先复现0°TMQ的380→390mm过渡及90°Steel01的350→360mm过渡，利用已保存端部历史检查关键杆；随后再分离步长、算法和本构切线影响。本轮没有执行这些修正，也没有据数值停止划定易损性等级。
