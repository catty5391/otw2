**推荐路线：以角钢专用 PHM 的完整公式作为新的实验分支，用几何和材性计算可确定的参数，用匹配边界的真实循环试验校核，再分阶段识别剩余参数。遗传算法可以作为工具，不应承担补足缺失试验信息或修正错误模型机制的任务。**

## 2. 当前TMQ与新增角钢PHM不能直接交换参数

当前 `initial_imperfection_material/tian_ma_qu/material.py` 是基于 Liu–Tian–Ma–Qu 2022 的分段直线构件原型，含额外尚未验证的小反转闭合规则。新英文论文作者为 Liu–Tian–Ma–Meng，使用非线性压缩下降段和非线性反向拉伸段。

| 物理含义 | 当前代码 | 2023角钢PHM |
|---|---|---|
| 拉伸强化斜率/E | `rho` | κ |
| 首次压屈峰/fy | `phi` | φ |
| 首压下降支 | `alpha`、`beta`，两段直线 | η1、η2、σa，非线性曲线 |
| 压屈后卸载 | `tau`等乘历史割线刚度 | νE，ν按当前反转点状态计算 |
| 反向拉伸恢复 | `mu`、`nu`等分段系数 | ξ1、ξ2和χ等，非线性段与直线段组合 |
| 后续峰 | 当前实现每次均为`eta`×首峰 | θ(λn, εp)×首峰 |
| 后续下降支 | `theta`、`kappa` | 非线性压缩包络及新的历史状态 |

因此，论文中的κ不是代码的`kappa`，论文中的θ也不是代码的`theta`。不能只改一组配置数值来宣称复现角钢PHM。建议以独立名称维护模型及版本，再做对照。

## 3. 哪些参数现在已有较好的获取办法

### 3.1 几何、钢材和连接先确定

- 从S2K或原始模型读取截面、杆长、材料等级，计算最小主轴惯性矩及回转半径；等边角钢不能用任意局部轴惯性矩代替最小主轴值。
- 有同批券样数据时固定实测E、fy；没有时使用明确标注的工程/文献假定，并单独做敏感性分析。其它试验的实测值不等于本塔钢材实测值。
- 确定长度与位移标距、初始缺陷形状与幅值、端部偏心和连接约束。有效长度系数K是边界问题，不能仅凭长度和截面给所有杆件统一取值。
- 用 `λ=KL/i_min`，再计算 `λn=(λ/π)√(fy/E)`。其中L是杆件长度，KL是计算长度。

### 3.2 首次压屈峰：公式初值与直接试验特征都可用

英文论文式(7a)与中文式(2)给出同一稳定系数拟合式。令 `a=1.028+0.196λn+λn²`，则

\[
\varphi=\frac{a-\sqrt{a^2-4\lambda_n^2}}{2\lambda_n^2},\qquad
|N_{cr,1}|=A f_y\varphi.
\]

计算时可用等价的 `φ=2/(a+sqrt(a*a-4λn²))`，避免小λn处相减消去。此处使用压缩峰值的正幅值；代码内部的拉压符号另行明确。

若有经过确认的首次压屈试验峰，可直接计算 `φ=|Ncr,1|/(Afy)`。预拉屈服后的第一次压峰不能当作未损伤试件的首次压峰。

### 3.3 下降支：回归公式比九参数盲搜更适合作初值

2023英文式(7c)、(7d)给出：

\[
\eta_1=-180.877+532.191e^{-0.240\lambda_n},\qquad
\eta_2=63.913-683.403e^{-0.455\lambda_n}.
\]

这些系数来自经试验核对的有限元模型和Riks分析后的回归，不是每根角钢都重新做一次GA。它们用于该论文的非线性下降公式，不能塞入当前两段直线的`alpha`、`beta`字段。

如果保留原TMQ形式，可用可靠试验或验证后的构件模型生成单调曲线，再在固定峰值、固定物理量下识别两段斜率；这叫数值或试验条件标定，不是独立验证。

### 3.4 后续压屈峰：应由历史状态更新

2023英文式(14)、(15)为

\[
|N_{cr,X}|=\theta |N_{cr,1}|,\qquad
\theta=(1+69.896\lambda_n\varepsilon_p)^{-1.566}.
\]

2022中文式(14)、(15)为

\[
\theta=(1+127.398\lambda_n\varepsilon_p)^{-1.136}.
\]

中文原文明确εp为**历史受拉加载时最大塑性应变**；英文写maximum historic plastic strain。它们都不能未经说明改成循环次数，也不能直接改成所有塑性增量绝对值的总和。实现时还需确定等效构件塑性应变的更新及与反转点的关系。

仅作公式演示，固定λn=1：

| εp | 2023英文θ | 2022中文θ |
|---:|---:|---:|
| 0 | 1.0000 | 1.0000 |
| 0.005 | 0.6254 | 0.5713 |
| 0.010 | 0.4360 | 0.3933 |
| 0.020 | 0.2542 | 0.2373 |

这说明两版都允许随历史塑性变形增长而降低后续峰，且同一输入下并不相同。上表不是本塔参数，也不是新完成的试验拟合。历史最大值不增长时，该式不会仅因多走一圈自动继续退化；同幅循环的累积疲劳仍需另外评价。

### 3.5 卸载、再加载和强化：用对应支路约束

角钢PHM部分恢复刚度由长细比和当前反转状态计算，降低了独立待拟合参数的数量。仍需核对χ、κ、关键转折点的生成方法及小循环规则，不能把公式中出现的字母都视为已获得数值。

保留当前模型时，可将直接可测的斜率/峰值用作初值，再分别用压缩卸载、拉伸恢复、高于屈服的拉伸支约束相关参数。只有弹性小循环时不能识别强化和屈曲后参数。GA多次找到近似目标值，但参数差异很大或持续撞边界时，应报告不可辨识或模型失配。

### 3.6 断裂参数需独立证据

新增角钢PHM包含εN、εM的失效终点，但正文出现这些变量不代表已经得到可迁移到本塔的取值。郑华冬论文有低周疲劳专章，可用于规划损伤识别。JCSR2022例题采用的拉伸0.3%、压缩为其3倍是该算例的失效设定，不能当作Q235/Q345角钢普适材料常数，也不能用券样伸长率直接代替构件等效断裂应变。

## 4. 新文件也存在需要查清的地方

1. **公式与图的符号口径。** 英文式(7b)印刷为 `σa=0.805−37.902 exp(−0.887λn)`；λn=1时为−14.8064，而图15的σa纵轴画为正值。可能涉及压应力符号/幅值表示，但正文未清楚统一。必须明确原式的符号与应力量纲，再通过压缩包络的极限值检查，不能悄悄改号。博士论文提取文本也给同一负号。
2. **中文分段区间印刷有重叠。** 中文式(12)首末区间分别印为 `0.6≤λn` 与 `λn≤1.7`，和中间段重叠；英文式(12)给出低、中、高长细比的有序分段。已目视核对两份PDF。英文在1.7处仍有端点重合，实际实现需记录端点归属及连续性检查。
3. **钢号和归一化不是完全一致。** 中文表2标Q345、英文表2标Q355，但两者5/7/8 mm对应的实测fy相同（364.3/367.7/358.7 MPa），尺寸和加载表也有重合。不能把两个钢号标签简单当作独立钢材批次。表中屈服位移还需核对使用名义fy还是实测fy。
4. **参数适用范围。** 英文12件试验的λ为50–140；数值参数扫描描述λ为40–120、b/t为5–23，图15显示更宽的λn回归样本。不能仅凭图的横坐标认定全部范围均有独立试验验证。Q420、不同连接及塔内复杂弯扭传力需要另行验证。
5. **初始缺陷仍重要。** 英文论文的缺陷敏感性算例中，循环回线整体变化较小，但首压屈曲峰有变化。不能将此结论推广成所有杆件都可忽略缺陷。等效本构与几何模型也不能重复计入同一杆内压屈机制。
6. **8%是论文特定耗能比较结果。** 它不表示所有应力点误差都低于8%，也不表示我们已经复现到8%。
7. **新模型仍有线性初始受压段。** 仅改成新PHM并不能自动解决Carden当前首峰位移过早的问题；标距、几何柔化、端部/夹具柔度仍须核对。

## 5. 怎样取得可用的试验历史

优先级建议如下：

1. 作者公开原始数据、附件，或经联系作者取得的有序力—位移记录，并配套几何、券样、连接和加载协议。本轮没有联系或向任何作者发信。
2. 从原作者PDF矢量图恢复路径。新英文论文PDF第10页图18含蓝色试验矢量线和红色PHM线，可优先审查；已确认该页没有位图图像且存在矢量路径，但**尚未完成试验线拼接、连续性、起始状态和加载顺序验收**。因此没有把它登记成可用于识别的真实历史。须避免抽到红色预测线后拿来做“试验拟合”。
3. 对栅格图，只提取明确可辨的峰值、分支斜率、零力位移等特征，或者逐分支人工核对；不按横坐标排序制造循环时程。
4. 用经独立试验核对的有限元模型补充参数覆盖。必须记录它是数值生成数据，先进行网格、步长及边界检查；不能把未经收敛的四分段模型当作真值。

相较Jain资料，本批角钢文献的截面、长度、约束和加载协议更贴近课题，适合成为主要复现来源。Carden保留作外部差异检查；如果看过Q结果后据此改变模型，Q就不再是完全未见的独立检验集，下一阶段应另设留出试件。

## 6. 和当前项目结果的关系

已有Carden条件识别使用实测E/fy、名义几何和作者有序绘图顶点，当前φ约0.7206，条件强化系数ρ约0.002819；完整P/Q曲线NRMSE仍为36.77%/32.19%。这些误差属于部分阶段识别加其它系数先验，不是原TMQ的最优可能精度，也不是新角钢PHM的误差。

现有问题包括首峰位置偏早、卸载参数触界、部分后续参数未被激励、固定后续峰无法反映观察中的渐降。新文献给出了新的建模依据，但不能以文献拟合图代替我们自己的实现验证。

详细已有结果见 [Carden条件识别报告](../../initial_imperfection_material/tian_ma_qu/followup_results/carden_conditional_20261026/REPORT.md)。

## 7. 推荐的实际执行顺序

1. 以2023英文角钢PHM为单一主版本，中文和博士论文用于交叉核对；先建参数符号、单位、状态变量与来源页码表，解决上述公式问题。
2. 从其12件试验挑选一个尺寸/边界清楚的试件做完整复现；S9/S10有实体模型与试验对照，适合调试，但它们也是作者既有验证样本，不能称新独立试验。
3. 优先检查图18的真实试验矢量路径能否恢复有序历史；不能恢复的部分保持“缺失/仅特征”，不推测插入。
4. 固定E/fy来源、A/L、K与标距口径。按公式先算φ、η1、η2及状态相关退化，暂不进行全参数搜索。无法核实的量列为假设范围。
5. 在隔离材料模块检验：弹性小循环恢复、首峰、下降支、压后卸载、恢复拉伸、后续压峰、小反转和越过已验证应变范围的行为。严格记录承诺状态与回滚状态，保证隐式迭代不会重复累积损伤。
6. 仅对仍缺失且确被试验激励的少数参数做分组识别；训练试件与留出试件预先固定，参数边界碰撞、灵敏度秩及不确定性一并报告。
7. 对本塔实际截面/长细比/钢号/连接分组，检查哪些在文献范围内、哪些属于外推。完成构件和塔段对照后再更新全塔材料。

若保留原TMQ九系数路线，可并行作为对照模型，给每组经验证构件离线标定；这是合理的工程简化方法，但需明确数值标定来源与适用范围。鉴于当前主要问题包含分支机制，优先复现有完整来源的角钢PHM比继续扩大GA搜索更值得做。
