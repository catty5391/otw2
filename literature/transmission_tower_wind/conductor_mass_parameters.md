# 输电导线质量参数与建模定义

整理日期：2026-10-19。

## 本项目的取值

当前塔线体系选用 `JL/G1A-400/50` 作为演示导线。贵州省生态环境厅公开的 220 kV
工程报告给出了下列参数：

| 参数 | 数值 |
|---|---:|
| 计算截面积 | 452 mm² |
| 计算外径 | 27.6 mm |
| 计算拉断力 | 123040 N |
| 弹性模量 | 69000 N/mm² |
| 单位质量 | 1510.3 kg/km |

来源：[贵州大龙电厂机组送电湖南配套工程环境影响报告，表 1-6](https://sthj.guizhou.gov.cn/xwzx/tzgg/202009/W020221227481943376498.pdf)。
该报告的实际工程是二分裂导线，但本项目当前每条 OpenSees 线元模型只表示一根物理子导线，因此
`bundle_count` 先取 1。

## 质量、自重和节点质量

参数表中的单位质量先换算为：

```text
μ_single = 1510.3 / 1000 = 1.5103 kg/m
```

若一条模型线代表 `n` 根分裂子导线：

```text
μ_model = n × μ_single                    [kg/m]
w_model = μ_model × g                     [N/m]
m_i = μ_model × L_tributary,i             [kg]
Pz_i = -w_model × L_tributary,i              [N]
```

当 `g = 9.81 m/s²` 且 `n = 1` 时，`w_model = 14.816 N/m`。原配置中的
`q_g = 15 N/m` 与此非常接近，但 `q_g` 是线自重，不是线质量。

`L_tributary,i` 按带初始弧垂的导线折线计算：端点取相邻线段长的一半，内点取左右
两段各一半。因此所有节点质量之和等于导线实际初始折线长度乘以单位长度质量。OpenSees
中 `mx = my = mz = m_i` 表示同一物理质量在三个平动自由度的惯性系数，不是把物理质量算了三遍。

## 配置方式

推荐在导线配置中写型号和分裂数：

```json
{
  "conductor": {
    "model": "JL/G1A-400/50",
    "bundle_count": 1
  },
  "gravity": 9.81
}
```

参数表在 `model/.config/conductor_catalog.json`。也可以直接填写
`conductor.mass_per_length`（单根子导线，kg/m）。代码仍兼容旧的 `q_g`（N/m），
但新配置应优先使用质量参数，再由重力加速度生成自重。

## 分裂导线的限制

如果以一条等效线元代表整相分裂导线，可把 `bundle_count` 改为 2、4 或其他实际数量；
但不能只改质量。`EA`、初始张力、风载投影面积也必须与等效方式一致。在没有 Z30103A6
实际导线型号和分裂施工图前，本次不自动把模型改成多分裂等效线。
