# 科研图表重构与复现

本次使用 nature-figure 技能整理现有 Python/Matplotlib 出图流程。目标是让已有数值证据更易比较；没有设定期刊投稿目标，不将版式检查解释为 Nature 投稿合规证明。

## 图表约定

|图组|要回答的问题|保留的证据与边界|
|---|---|---|
|全塔推覆|三种建模方案在不同风角下何时出现非线性、在哪里停止？|全部已接受点、终点标记、四个风角；保留钢材屈服与 TMQ 压屈标准不同的说明|
|四分段 Steel02 / TMQ 单杆|骨架、完整循环和网格差异如何影响等效判断？|既有全部对照曲线和网格数据；不把较密网格视作精确解|
|曲线型角钢 PHM|曲线本构在哪些分支拟合有效，完整历史在哪里失效？|原有拟合、残差、失败前缀和完整观测；不平滑真实折线和不收敛端点|
|TMQ 单杆|完整加载过程与屈曲机制是否在记录中出现？|完整滞回、载荷顺序与机制检查；演示循环不是原试验复现|
|单塔 / 塔线静风|新旧建模方案及风攻角的响应差异是多少？|共同可比范围及所有平衡点；空心标记保留轴向假设超限提示|
|雨荷载|粒径谱如何变为荷载，数值检查和实际塔静力响应支持到哪里？|雨强闭合、合成时程、荷载谱、泊松冲量、塔线映射和实际静力；人为输入不改称实测|

采用定量多面板图：单组围绕原有力学问题组织，对照工况使用可比坐标。保留原有单位与正负号：m→mm、N→kN等转换仍由原绘图函数执行。纵轴截断、对数坐标及原有数据筛选沿用原图定义，重构层不新增删点、插值、拟合或误差条。当前是确定性算例，不凭空添加统计不确定性。

## 公共接口

`scientific_figures.save_figure(fig, path)` 对现有图进行字体、线宽、图例、面板和导出设置。输出同名 PNG（300 dpi）、SVG（可编辑文字）、PDF（TrueType文字），并保存图元数据哈希和质量记录。多列图宽183 mm，单列图宽120 mm；高度按内容安排，未强称适用所有投稿尺寸。

Steel01 用灰色点划线，Steel02 用蓝色（16段使用虚线），TMQ 用朱红色虚线，曲线 PHM 用紫色。图例放在数据区外，避免遮挡滞回及停止点。标题与图例过长时换行，不删除科学限定。

设置 `OTW2_FIGURE_SKILL` 指向 nature-figure 技能目录后，调用技能的面板对齐、PDF字号与碰撞审计。默认对齐误差1.5 pt、字形下限5 pt；未设置时质量记录明确写 `not_run`。审核工具需要 PyMuPDF，可用 `uv pip install --python .venv/bin/python 'pymupdf>=1.24,<2'` 安装。技能不作为 OpenSees 求解的依赖。

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 .venv/bin/python -m scripts.rebuild_scientific_figures \
  --skill-root "$HOME/.codex/skills/nature-figure"
# 可选 --groups tower steel02 liu tmq single_wind tower_line rain
```

重绘先进入 `artifacts/figure_refactor_20261106/`，不覆盖计算输入。每组记录输入文件哈希，每幅图对比样式设置前后的全部线、散点、色块及柱形数据几何。只有完成自动审计和人工检查的图才复制到网页原图地址。生成图、PDF和大数据保留本地，Git仅同步脚本、测试和说明。

## 本轮完成结果（2026-11-06）

共7组37幅：全塔推覆5幅、Steel02/TMQ单杆8幅、PHM曲线型材料4幅、TMQ完整历史与机制3幅、单塔静风3幅、塔线静风6幅、雨荷载8幅。原模块图已更新，并增加[独立图册](http://localhost:9999/scientific-figures/)。历史模态、三维图、旧等效材料及未列入的敏感性图保持既有版本。

37幅全部通过最终面板对齐、PDF字号和碰撞审计，所有样式变换前后的数据图元哈希一致。原有TMQ原生校核散点曾按约85点抽样，本轮改为显示全部已保存点；主滞回曲线不删点、不排序。局部放大图中，超出坐标范围的长线采用300 dpi栅格化以正确保留裁剪效果，坐标和文字仍可编辑；不是所有线条都承诺纯矢量。

相关回归43项通过，最终导出测试5项通过，其中3项重复，合计45项独立测试通过。111个网页图文件均返回200且与本地字节一致；桌面1440px与手机390px的37张图全部成功解码，无横向溢出或脚本错误。浏览器第一次并行解码失败，顺序解码重试通过，失败记录未计作通过。[小型检查汇总](../../validation/figure_refactor_20261106/summary.json)。

技能静态检查不能跨文件追踪公共导出函数，单文件会出现字体、导出、对齐检查缺失的提示；将实际调用模块和公共导出源码合并做只读预检后，无FAIL。5条WARN逐项处理如下：PNG300 dpi用于浏览，另有PDF/SVG，不要求TIFF/600 dpi；源函数的初始尺寸由公共出口统一调整，最终尺寸见测量记录；雨强插值节点固定为0、150、250、400、500、600，严格递增；所画确定性算例、单次合成序列及解析均值并非跨样本统计汇总，因此不添加虚构误差带。

重新绘制后发布可追加 `--publish`；只发布已通过审计的现有导出使用 `--publish-only`。脚本在替换任何旧图之前检查整组文件，备份在本地输出目录的 `previous/` 下。桌面/移动端复查入口为 `py_view/results_dashboard/figure_smoke.cjs`，需要可用的 Playwright。
